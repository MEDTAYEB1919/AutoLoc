# AutoLoc

Plateforme de gestion de location de véhicules multi-agences (étude de cas UP ASI, ESPRIT).

## Objectifs du projet
- Gérer le parc de véhicules de plusieurs agences (disponibilité, catégories, tarifs).
- Permettre aux clients de réserver un véhicule et de suivre leurs contrats et paiements.
- Suivre la maintenance des véhicules et les équipements associés.
- Construire une API REST avec Spring Boot, Spring Data JPA et MySQL.

## Acteurs identifiés
- **Client** : consulte les véhicules, réserve, signe un contrat et paie.
- **Agent d'agence** : gère les réservations, les contrats et les paiements au quotidien.
- **Responsable d'agence** : supervise l'agence, son personnel et son parc de véhicules.
- **Administrateur** : administre la plateforme, les agences et les comptes.

## Stack technique
Java 17, Maven, Spring Boot, Spring Data JPA, MySQL, Lombok.
